# RecoverySys 1.3.0-rc.3

Test candidate, 2026-11-07. Supersedes the unpublished 1.3.0-rc.2 draft, whose
archives still carry the old 46 g mass for the 96" Iris Ultra Compact. This is
not a stable release or a physical-flight qualification.

## Changes since rc.2

- Corrects the 96" Iris Ultra Compact (Spectra) catalog mass from 46 g to
  462 g (manufacturer specification 16.3 oz). Hardware mass is informational;
  simulated and entered rocket mass are unchanged. Saved catalog selections
  pick up the new weight on reload; custom copies keep their entered values.
- Includes everything in [rc.2](1.3.0-rc.2.md): series-chain compatibility
  findings, print provenance, OpenRocket regressions and Node 22/24/26 support.

## Automated build

Archives are built by the `Node checks` workflow on the tagged commit; hashes
are recorded in the GitHub release and in
`history/release-rc3-2026-11-07/EVIDENCE.json`.

## Opening on macOS

The macOS archive is ad-hoc signed, not notarized. After extracting it,
right-click `RecoverySys.app` in Finder and choose **Open**, then confirm the
prompt. If macOS still blocks the app, open **System Settings → Privacy &
Security** and choose **Open Anyway**, or remove quarantine from this app only:
`xattr -dr com.apple.quarantine /path/to/RecoverySys.app`. Do not disable
Gatekeeper globally.

## Not established

- No manual Windows or macOS workflow; Intel Mac launch untested.
- No observed rocketeer trials, independent physics acceptance or accepted
  real-flight cases.
- Not a stable promotion.
