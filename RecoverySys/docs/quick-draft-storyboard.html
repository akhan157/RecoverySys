What this walkthrough is testing

  • Parts and the draft remain adjacent during exploration.
  • Missing inputs explain unavailable checks without blocking editing.
  • Replacement preserves context and distinguishes quick checks from stale system results.
  • Requirements, custom architecture and evidence deepen the same plan.

This artifact does not validate the physics, prove user task times, implement saving or import files. It is a visual review of the agreed interaction hierarchy.
