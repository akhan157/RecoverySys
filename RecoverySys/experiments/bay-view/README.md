# Deferred bay size-view experiment

Removed from the V1 interface after user review found limited practical value.
Nothing here is imported by the application or included in the production build.
Three.js is a development dependency solely for this retained prototype.

Files preserve the individual size-reference approach and its tests. The tests
are outside the production test include path. To reconsider this feature, first
validate a concrete assembly-review task, acquire sourced rigid geometry and
measured packing states, and review an interactive prototype with users.
No view here establishes physical fit, occupied volume or deployment clearance.
